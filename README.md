# Athoo Evolution WhatsApp

Private deployment wrapper for running Evolution API as Athoo's low-cost WhatsApp delivery service.

## Architecture

Athoo backend -> Evolution API -> WhatsApp (Baileys)

Authentication remains in the Athoo backend. Evolution API is only the WhatsApp delivery transport. Email should remain available as an OTP fallback.

## Deployment

This repository is prepared for a Render Docker Web Service using `render.yaml`.

Before deployment, provide these secret/environment values in Render:

- `SERVER_URL` - the final public Render service URL
- `DATABASE_CONNECTION_URI` - PostgreSQL connection URI
- `CACHE_REDIS_URI` - Redis connection URI
- `AUTHENTICATION_API_KEY` - generated by the Render Blueprint unless manually overridden

Never commit real credentials to this repository.

## Important

The free Render tier is suitable for development/testing but may sleep when idle. Baileys is an unofficial WhatsApp Web integration and is less reliable than Meta's official WhatsApp Cloud API. Keep an email OTP fallback for Athoo authentication.
